## 1. 项目概述

**项目名称**：blogtry
**技术栈**：Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router
**项目类型**：博客后台管理系统
**主要功能**：文章管理、动态管理、友链管理、评论管理、系统设置等完整的博客后台功能

## 5. 技术难点与解决方案

### 5.1 Token 刷新机制

- **难点**：处理 Token 过期和刷新，避免用户登录状态丢失

- 解决方案

  ：

  - 响应拦截器捕获 401 错误
  - 实现 Token 刷新队列，避免并发请求重复刷新
  - 刷新失败时自动跳转到登录页
  - ## 
    ### 1. 并发请求处理
    难点 ：当多个请求同时因 Token 过期而失败时，可能会触发多次 Token 刷新。
  
    解决方案 ：
  
    - 使用 isRefreshing 标志确保同一时间只进行一次 Token 刷新
    - 将并发请求加入队列，待 Token 刷新后统一处理
    ### 2. Token 存储安全
    难点 ：如何安全存储 Refresh Token。
  
    解决方案 ：
  
    - 使用 localStorage 存储，便于跨标签页共享
    - 考虑在生产环境中使用 httpOnly cookie 存储 Refresh Token，进一步提高安全性
    ### 3. 错误处理
    难点 ：如何处理 Token 刷新失败的情况。
  
    解决方案 ：
  
    - 完善的 try-catch 错误处理
    - 刷新失败时清空 Token 并跳转到登录页
    - 向用户提供清晰的错误提示
    ### 4. 边界情况
    难点 ：处理 refresh 接口本身的认证问题，避免死循环。
  
    解决方案 ：
  
    - 在请求拦截器中特殊处理 refresh 接口，不添加 Access Token
    - 在响应拦截器中检测请求 URL，避免对 refresh 接口的 401 错误进行递归处理
